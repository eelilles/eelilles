Photos are the single best documentation tool for your build. They cost nothing, take seconds, and can be invaluable for resolving disputes, filing insurance claims, and maintaining your home. But random photos aren't useful—you need a systematic approach.

## Why Documentation Matters

### During Construction

- Verify work matches specifications
- Record hidden work before it's covered
- Support change order discussions
- Document issues for resolution
- Prove completion for draw requests

### After Construction

- Reference for maintenance and repairs
- Insurance documentation
- Warranty claims support
- Future renovation planning
- Property sale documentation

## What to Photograph

### Before Construction

- [ ] Existing site conditions
- [ ] Vegetation and features to preserve
- [ ] Property boundaries and markers
- [ ] Access routes
- [ ] Neighbouring structures
- [ ] Utility locations

### Foundation Phase

- [ ] Excavation before concrete
- [ ] Footing forms and rebar
- [ ] Footings before backfill
- [ ] Foundation walls and waterproofing
- [ ] Drainage system before burial
- [ ] Foundation before backfill (all sides)
- [ ] Anchor bolt locations
- [ ] Any issues or defects

### Framing Phase

- [ ] Floor framing and blocking
- [ ] Wall framing (each wall)
- [ ] Beam and header locations
- [ ] Connection details
- [ ] Roof framing
- [ ] Sheathing and air barrier
- [ ] Window and door rough openings

### Rough-In Phase (Critical)

This is the most important documentation phase—everything gets covered up.

**Electrical**
- [ ] Panel location and mounting
- [ ] Each outlet and switch box location
- [ ] All wire runs (especially unusual ones)
- [ ] Low-voltage rough-in
- [ ] Exterior penetrations

**Plumbing**
- [ ] Drain and vent locations
- [ ] Supply line routes
- [ ] Fixture rough-in locations
- [ ] Water heater location
- [ ] Shut-off valve locations
- [ ] Pressure test documentation

**HVAC**
- [ ] Duct locations and routing
- [ ] Equipment locations
- [ ] Vent locations
- [ ] Any in-floor heating

**Insulation**
- [ ] Wall cavity insulation
- [ ] Ceiling/attic insulation
- [ ] Foundation insulation
- [ ] Air sealing details

### Finish Phase

- [ ] Drywall before texture/paint
- [ ] Any defects before painting
- [ ] Final finishes (flooring, trim, etc.)
- [ ] Cabinet installation
- [ ] Countertop installation
- [ ] Fixture installation
- [ ] Appliance installation

### Exterior

- [ ] Foundation waterproofing
- [ ] Housewrap and flashing
- [ ] Siding installation progression
- [ ] Roofing installation
- [ ] Window and door flashing
- [ ] Exterior trim details
- [ ] Final grading
- [ ] Drainage swales and slopes

### Final Documentation

- [ ] Each room, all angles
- [ ] All exterior elevations
- [ ] Mechanical equipment with labels
- [ ] Panel box with breaker labels
- [ ] Shut-off valve locations
- [ ] Any serial numbers/model numbers

## How to Take Useful Photos

### Technical Tips

- **Use good lighting**: Turn on lights, open blinds, use flash if needed
- **Show context**: Include surrounding area to locate the subject
- **Get close-ups**: Detail shots of connections, labels, defects
- **Multiple angles**: Different perspectives reveal different information
- **Include reference**: Use a tape measure, level, or person for scale

### Organizational Tips

- **Date every photo**: Enable timestamp in camera settings
- **Use a consistent naming convention**: Date_Area_Subject
- **Take notes**: Written descriptions supplement photos
- **Back up immediately**: Don't rely on a single device
- **Organize by phase**: Create folders for each construction stage

### What Makes a Photo Useful

**Good photo**: Shows the entire wall with all outlet boxes visible, tape measure in frame, date stamp, taken from two angles.

**Poor photo**: Close-up of one outlet box, no context, no date, blurry.

## Photo Schedule by Phase

### Weekly Minimums

- Exterior from all four sides
- Interior overview of each active area
- Any in-progress work

### At Each Inspection

- Photograph inspector's arrival
- Capture all areas being inspected
- Photograph the signed permit card
- Note any corrections required

### Before Covering Work

- All rough-in before insulation
- All insulation before drywall
- All blocking and backing before drywall
- All waterproofing before backfill

### At Each Milestone

- Foundation complete
- Framing complete
- Rough-in complete
- Drywall complete
- Substantial completion
- Final completion

## Storage and Backup

### During Construction

- Cloud backup enabled on phone
- Weekly download to computer
- Monthly backup to external drive
- Share access with builder (optional)

### After Construction

- Organize by category and phase
- Create a "critical" folder with most important images
- Store with other home documents
- Include copies with insurance documentation
